Geminiの鍵

鍵はこのスマホの中だけに保存され、写真は直接Googleに送られます。

🔑 鍵のページを開く（Google AI Studio）
  1. 上の青いボタンを押す（Googleのページが開きます）
  2. 鍵（AIza…で始まる文字）の右の「コピー」の印を押す
    ※ 鍵がまだないときは「APIキーを作成」（Create API key）を押す
  3. このアプリに戻り、下の「📋 貼り付け」を押す
  4. 「保存」を押す

読み取りの速さ

ふりがなの付いた言葉に触れると、詳しい説明が出ます。違う漢字のときは、拡大して漢字の真ん中に触れ直してください。
